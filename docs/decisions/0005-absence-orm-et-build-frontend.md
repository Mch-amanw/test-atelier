# ADR-0005 : Absence d’ORM et de build frontend

## Contexte
Le projet vise une architecture minimaliste et facilement compréhensible.

## Décision
Le projet n’utilise ni ORM ni chaîne de build frontend.

## Conséquences
- Réduction de la complexité technique.
- Frontend servi sous forme de fichiers statiques.
- Accès direct SQL côté backend.
